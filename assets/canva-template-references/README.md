# Canva template references

This folder stores the Canva URLs that inspired the native RenderAI brochure library.

The actual Canva template files are not stored here because the current Canva connector cannot download public Canva templates as editable files, and brand-template access requires Canva Enterprise. The app should use these links as design references only and keep all production previews/layouts native to this repo.

Runtime brochure previews live in `assets/template-previews/`.
